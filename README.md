# Git-RepoIntel 🚀

**Turn engineering activity into buying signals.**

Git-RepoIntel is an AI-powered B2B intelligence tool that analyzes public GitHub activity to detect real-time buying intent signals for sales, product, and growth teams.

---

## 💡 The Idea

Traditional sales tools rely on weak signals like website visits or email opens.

Git-RepoIntel flips this by analyzing **engineering behavior**, the strongest indicator of what a company is about to buy.

---

## ⚙️ How It Works

1. Input a GitHub organization
2. Fetch recent engineering activity
3. Extract meaningful signals (infra, scaling, security, etc.)
4. Generate business insights using AI

---

## 🧠 Features (MVP)

- GitHub activity analysis (repos, commits, contributors)
- Keyword-based signal detection
- Custom user-defined context
- Signal scoring system
- Structured output for AI intelligence generation
